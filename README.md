# AdmTecnicoCelulares

CelluFix es una aplicación de gestión para servicios técnicos de celulares.

## Estructura

- `frontend/`: React, TypeScript, Vite y Material UI.
- `backend/`: Node.js, Express, TypeScript, Prisma y PostgreSQL.

## Desarrollo

Instalar dependencias en la raíz, frontend y backend. Luego:

```bash
npm run dev
```

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:3000`

La configuración de PostgreSQL y el procedimiento de migración desde SQLite se
encuentran en [`backend/README.md`](backend/README.md).
